This client uses WebTorrent, so it only connects to peers that support WebRTC (browser and some desktop clients). Many regular torrents will find no peers here. For those, run a server-side client such as qBittorrent or Transmission. Streaming works for MP4, WebM, MP3, M4A, OGG and WAV files. MKV and AVI can’t play in the browser, so save those instead. Only download content you have the right to share.
